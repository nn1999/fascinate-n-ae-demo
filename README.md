# 复旦肿瘤医院乳腺外科 · AE随访演示

独立于NeoMARS原Demo。双端UI复用v1.11，保留AE采集、两版CTCAE独立确认、四药相关性、后续处置与转归、量表及治疗进展提醒。

全部病例为模拟数据；处方为经用户确认的交互演示参考安排，不能用于真实治疗。不是FASCINATE-N完整试验系统。

浏览器内保存状态；无真实电话外呼或后台医疗记录；v1.9图片OCR在浏览器本地执行，PDF仅保存待核对。音频为预生成问句，语音转写取决于浏览器支持。网页不含语音服务密钥。

医学资料：NCT05582499登记、公开方案V2.1、NCI CTCAE v5.0/v6.0，详见notes。

最新版本：[v1.9](https://nn1999.github.io/fascinate-n-ae-demo/v1.9/)。真实麦克风输入、通话内病历上传、缺项追问、书面处置摘要与药物文献引用。所有旧版本保留。
